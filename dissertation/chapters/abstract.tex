% Abstract

Coordinating multiple agents for fruit harvesting is not straightforward. While communication lets them share information about resource locations, it comes with costs: bandwidth gets consumed, processing power gets tied up handling messages. The question is: Does the distance over which agents can communicate actually matter for how much fruit they harvest? And if so, how? This dissertation explores that question through simulation.

Using Mesa 3.0, I have implemented a grid-based environment where harvesting agents roam around looking for fruits. When they find some, they tell other agents in their communication range where they are. Agent behaviors are deliberately simple: move, harvest when you encounter fruit, and share what you find with nearby agents. The experiments test five different communication ranges across multiple team sizes and resource densities in static environments where fruit doesn't regenerate once picked.

The main research question is: does communication range actually matter for collective harvest performance? Through systematic experimentation with 400 simulation runs, I analyze how communication range affects harvesting efficiency, message overhead, and coverage. Results show that communication range has a significant effect on yield, with an optimal range that balances information sharing against message costs.

\textbf{Keywords:} Multi-agent systems, communication protocols, fruit harvesting, agent-based modeling, Mesa framework
