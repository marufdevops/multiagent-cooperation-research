% Abstract

Effective coordination in multi-agent systems requires balancing information sharing against communication costs. This dissertation investigates how communication range affects harvesting efficiency in multi-agent resource collection tasks. While communication enables agents to share information about resource locations, it incurs computational and bandwidth overhead. The central research question is: what communication range optimizes the trade-off between coordination benefits and communication costs?

This work presents a Mesa 3.0-based simulation framework implementing a grid-based harvesting environment with range-limited agent communication. Agents employ sophisticated search behaviors incorporating Tier 1 algorithm improvements: Levy Flight for exploration, Visited Cell Memory to avoid redundancy, Density Heatmap for clustering detection, and Target Validation to prevent stale targets. These improvements enhance search efficiency beyond baseline random walk. Systematic experimentation across five communication ranges (0, 2, 4, 6, 8 cells), two team sizes (10, 20 agents), and two resource densities (0.15, 0.25) with 20 replications per configuration (400 total runs) provides empirical evidence of communication range effects.

Results demonstrate that communication range significantly affects harvesting efficiency, with a 38.9\% improvement from communication-enabled agents compared to isolated agents. Analysis reveals that moderate communication ranges (r=2) achieve near-optimal performance while minimizing message overhead, suggesting that local communication provides superior cost-benefit trade-offs compared to longer-range communication. These findings have implications for designing efficient multi-agent coordination protocols in resource-constrained environments.

\textbf{Keywords:} Multi-agent systems, communication protocols, resource harvesting, agent-based modeling, Mesa framework, coordination efficiency
