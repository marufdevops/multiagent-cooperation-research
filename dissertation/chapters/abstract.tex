% Abstract

Multi-agent systems for resource gathering tasks, such as fruit harvesting, require coordination to improve collective performance. Communication among agents enables information sharing about resource locations, but introduces costs in terms of bandwidth and processing. This dissertation explores how communication range affects collective yield in a grid-based multi-agent fruit harvesting simulation.

Using the Mesa 3.0 agent-based modeling framework, we implement a basic simulation environment where autonomous harvester agents navigate a spatial grid, locate fruit resources, and share information with teammates within a configurable communication range. The simulation includes agent behaviors for movement, harvesting, and communication, along with two resource dynamics modes: Static (non-regenerating) and Replenishing (regenerating resources).

This early-stage work (Weeks 1-2) presents the foundational implementation and a preliminary literature review. The simulation successfully demonstrates basic multi-agent coordination with communication, collecting metrics on total yield, messages sent, and remaining fruit. Interactive visualization allows real-time observation of agent behaviors and communication patterns.

Future work will involve systematic experimentation across different communication ranges, team sizes, and environmental conditions to identify optimal communication strategies. Statistical analysis will be conducted to determine significant effects and provide evidence-based recommendations.

This research aims to contribute to multi-agent systems and agricultural robotics by investigating communication range selection for cooperative robot teams. The findings may have practical applications in precision agriculture and related domains.

\textbf{Keywords:} Multi-agent systems, communication protocols, fruit harvesting, agent-based modeling, Mesa framework
