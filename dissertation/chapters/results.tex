% Results

This chapter presents the experimental results from 400 simulation runs investigating RQ1: "Does communication range affect harvesting efficiency in multi-agent systems?"

\section{Experimental Execution}

The experiments were executed successfully with the following parameters:

\begin{itemize}
    \item \textbf{Total runs:} 400 simulations
    \item \textbf{Communication ranges tested:} $r \in \{0, 2, 4, 6, 8\}$ cells
    \item \textbf{Team sizes:} 10 and 20 agents
    \item \textbf{Resource densities:} 0.15 and 0.25 (proportion of cells with fruit)
    \item \textbf{Replications per configuration:} 20 runs
    \item \textbf{Episode length:} 500 time steps
    \item \textbf{Grid size:} 50×50 cells
    \item \textbf{Total execution time:} 2.54 minutes (0.38 seconds per run)
\end{itemize}

All runs completed successfully with no errors or anomalies.

\section{Key Findings}

\subsection{Communication Range Dramatically Affects Yield}

The most striking finding is that communication range has a substantial effect on harvesting performance:

\begin{itemize}
    \item \textbf{No communication (range 0):} Mean yield of 354.61 fruits
    \item \textbf{With communication (ranges 2-8):} Mean yields of 487-500 fruits
    \item \textbf{Improvement:} 37-41\% increase in yield when communication is enabled
\end{itemize}

This clearly demonstrates that communication is valuable for multi-agent coordination in harvesting tasks.

\subsection{Optimal Range is Range 2}

While ranges 4, 6, and 8 all achieve similar yields (499-500 fruits), range 2 stands out as the most efficient:

\begin{itemize}
    \item \textbf{Range 2:} 487.48 yield with 682.75 messages (efficiency: 0.77)
    \item \textbf{Range 4:} 499.56 yield with 919.80 messages (efficiency: 0.55)
    \item \textbf{Range 6:} 499.80 yield with 993.12 messages (efficiency: 0.51)
    \item \textbf{Range 8:} 498.58 yield with 1013.11 messages (efficiency: 0.49)
\end{itemize}

Range 2 achieves 97.6\% of the maximum yield while using only 67.5\% of the messages required by range 8. This suggests that a moderate communication range provides the best cost-benefit trade-off.

\subsection{Diminishing Returns at Larger Ranges}

Ranges 4, 6, and 8 show a plateau effect: they achieve nearly identical yields (within 1.2 fruits of each other) despite increasingly higher message overhead. This indicates that beyond range 4, additional communication provides minimal benefit while significantly increasing computational and communication costs.

\subsection{Consistency Across Configurations}

The pattern holds consistently across different team sizes and resource densities:

\begin{itemize}
    \item Larger teams (20 agents) show similar patterns to smaller teams (10 agents)
    \item Sparse environments (density 0.15) and denser environments (density 0.25) both show communication benefits
    \item The relative ranking of ranges remains consistent: 0 < 2 < 4 ≈ 6 ≈ 8
\end{itemize}

\section{Answer to RQ1}

\textbf{Research Question:} Does communication range affect harvesting efficiency in multi-agent systems, and if so, how?

\textbf{Answer:} Yes, communication range has a dramatic and consistent effect on harvesting efficiency. The experimental results show:

\begin{enumerate}
    \item Communication is essential: agents with no communication (range 0) harvest 37-41\% fewer fruits than agents with communication
    \item There is an optimal range: range 2 provides the best efficiency (yield per message)
    \item Larger ranges show diminishing returns: ranges 4, 6, and 8 achieve similar yields despite increasingly higher message costs
    \item The effect is robust: the pattern holds across different team sizes and resource densities
\end{enumerate}

These findings directly support the hypothesis that communication range is a critical parameter for multi-agent coordination in harvesting tasks.
