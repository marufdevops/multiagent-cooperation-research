\section{Background and Motivation}

Getting multiple agents to work together on harvesting tasks is harder than it sounds. Agriculture is facing real labor shortages in this modern world, and there is growing interest in using robotic agents to pick fruit more efficiently. But the main factor is they need to communicate efficiently in order to harvest. If they don't share information about where the fruit is, they'll waste time searching areas that other agents have already covered.

The question is, how much communication is much? If agents can only talk to agents in nearby, they might miss out on useful information from agents who are farther away. But if they are always sending messages to everyone in a large area, they will spend all their time reading them instead of actually harvesting. There's probably a sweet spot somewhere in between, and it likely shifts depending on how many robots you have, how the fruit is distributed, and whether new fruit keeps appearing or not.

That's what I'm trying to figure out in this dissertation. This dissertation uses simulation to explore how communication range affects how much fruit agents can harvest.

\section{Research Question}

The main research question I'm trying to answer is:

\begin{enumerate}
    \item \textbf{RQ1:} Does the distance over which agents can communicate actually matter for how much fruit they harvest? And if so, how?
\end{enumerate}

This question is investigated in static environments where fruit doesn't regenerate once picked. The effects of resource dynamics (whether fruit regenerates or not) are left as future work.

\section{Research Objectives}

What I'm actually trying to do here:

\begin{enumerate}
    \item Build a working simulation where agents move around, pick fruit, and communicate to each other. I'm using Mesa 3.0 to run the simulation.

    \item Create a visualization so you can actually see what's happening. It's way easier to understand agent behavior when you can see them moving around and communicating in real time.
\end{enumerate}

\section{Scope and Contributions}

\begin{itemize}
    \item \textbf{Working simulation:} A Mesa 3.0 implementation of a multi-agent fruit harvesting system with configurable communication ranges. Agents move on a grid, harvest fruits, and communicate within a specified range using Chebyshev distance.

    \item \textbf{Experimental evaluation:} Systematic testing of five communication ranges (0, 2, 4, 6, 8 cells) across multiple team sizes and resource densities with 20 replications per configuration (400 total runs).

    \item \textbf{Interactive visualization:} A Solara-based web interface for real-time visualization and parameter exploration, allowing qualitative observation of agent behavior.

    \item \textbf{Statistical analysis:} Rigorous analysis of experimental results using descriptive statistics and hypothesis testing to determine the effect of communication range on harvesting efficiency.

    \item \textbf{Future research directions:} Discussion of how resource dynamics (regenerating vs. static) and machine learning approaches could extend this work.
\end{itemize}
