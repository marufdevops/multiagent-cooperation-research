\section{Background and Motivation}

Multi-agent coordination in resource harvesting tasks presents significant challenges in both theoretical and practical domains. Agricultural automation increasingly relies on robotic agents to perform harvesting operations, yet the efficiency of such systems depends critically on effective information sharing among agents. Without communication, agents waste computational resources searching areas already explored by other team members, leading to suboptimal resource utilization.

The fundamental challenge is determining the optimal communication range for a given task environment. Limited communication ranges may prevent agents from accessing valuable information from distant team members, while excessive communication ranges incur substantial computational and bandwidth costs without proportional performance gains. This trade-off between coordination benefits and communication overhead is central to multi-agent system design.

This dissertation investigates how communication range affects harvesting efficiency in multi-agent systems through systematic simulation and empirical analysis. The research employs a Mesa 3.0-based simulation framework to explore this relationship across varying team sizes and resource densities.

\section{Research Question}

This dissertation addresses the following primary research question:

\begin{enumerate}
    \item \textbf{RQ1:} How does communication range affect harvesting efficiency in multi-agent systems, and what is the optimal range for different task configurations?
\end{enumerate}

This investigation focuses on static resource environments where harvested fruit does not regenerate. The effects of dynamic resource regeneration are deferred to future research.

\section{Research Objectives}

The primary objectives of this research are:

\begin{enumerate}
    \item Develop a functional multi-agent simulation framework using Mesa 3.0 that implements agents capable of movement, resource harvesting, and range-limited communication.

    \item Conduct systematic experimental evaluation across multiple communication ranges and task configurations to quantify the relationship between communication range and harvesting efficiency.

    \item Provide interactive visualization tools to facilitate qualitative analysis of agent behavior and communication patterns.
\end{enumerate}

\section{Scope and Contributions}

The key contributions of this work are:

\begin{itemize}
    \item \textbf{Simulation Framework:} A Mesa 3.0-based implementation of a multi-agent harvesting system with configurable communication ranges, employing Chebyshev distance metrics for range-limited communication.

    \item \textbf{Algorithm Improvements:} Implementation of Tier 1 algorithm enhancements including Levy Flight for exploration, Visited Cell Memory to eliminate redundancy, Density Heatmap for clustering detection, and Target Validation to prevent stale targets. These improvements enhance search efficiency beyond baseline random walk, expected to increase yields by 40-60\%.

    \item \textbf{Empirical Evaluation:} Comprehensive experimental analysis across five communication ranges (0, 2, 4, 6, 8 cells), two team sizes (10, 20 agents), and two resource densities (0.15, 0.25), with 20 replications per configuration (400 total runs).

    \item \textbf{Visualization Infrastructure:} Interactive Solara-based web interface enabling real-time observation of agent behavior and communication patterns.

    \item \textbf{Quantitative Results:} Empirical evidence demonstrating that communication range significantly affects harvesting efficiency, with identification of optimal range parameters for cost-benefit trade-offs.

    \item \textbf{Future Research Agenda:} Theoretical framework for extending this work to dynamic resource environments and machine learning-based coordination strategies.
\end{itemize}
