\section{Research Design and Rationale}

The purpose of this dissertation is to find out how communication range affects how well multiple agents work together in a harvesting task. The study doesn't use reinforcement learning or evolution to find the best communication policy. Instead, it uses a controlled, empirical design: a fixed and understandable communication protocol is tested across a discrete set of communication ranges, while other aspects of agent behavior stay the same.

This approach is appropriate for several reasons:

\begin{enumerate}
    \item \textbf{Causal interpretation:} By varying only communication range while controlling other factors, observed performance differences can be directly attributed to range effects rather than confounding variables.

    \item \textbf{Systematic exploration:} The design enables comprehensive investigation of interactions between communication range, team size, and resource density through factorial experimentation.

    \item \textbf{Reproducibility:} Fixed agent behaviors and explicit communication protocols ensure that results are reproducible and verifiable, unlike learned policies that may vary across training runs.

    \item \textbf{Interpretability:} An engineered communication policy makes results explainable in terms of agent behaviors and information flow, supporting practical design insights.

    \item \textbf{Computational efficiency:} Avoiding the computational overhead of learning algorithms enables extensive parameter sweeps with multiple replications for statistical robustness.
\end{enumerate}

The methodology follows a simulation-based experimental approach using agent-based modeling (ABM). This paradigm is well-suited for studying emergent coordination phenomena where system-level outcomes arise from local agent interactions.

\section{Problem Formulation}

\subsection{Environment Model}

Consider a discrete grid environment $\mathcal{G} = \{(x,y) : 0 \le x < W, 0 \le y < H\}$ where $W$ and $H$ are the grid width and height. The environment contains:

\begin{itemize}
    \item A set of $N$ autonomous harvesting agents $\mathcal{A} = \{a_1, a_2, \ldots, a_N\}$
    \item A set of fruit resources $\mathcal{F} \subseteq \mathcal{G}$ distributed across grid cells
    \item No obstacles or terrain constraints (all cells are traversable)
\end{itemize}

Each agent $a_i$ has a position $p_i = (x_i, y_i) \in \mathcal{G}$ and can move to any of the 8 adjacent cells (Moore neighborhood) in a single time step. Agents can occupy the same cell simultaneously.

\subsection{Objective Function}

The collective objective is to maximize the total harvest yield over a finite time horizon $T$:

\begin{equation}
Y = \sum_{t=1}^{T} \sum_{i=1}^{N} h_i(t)
\end{equation}

where $h_i(t)$ is the number of fruit items harvested by agent $i$ at time step $t$. An agent harvests all fruit present in its current cell, removing it from the environment.

\subsection{Communication Model}

Communication is range-limited based on Chebyshev distance (also known as the $L_\infty$ metric or chessboard distance). Two agents $a_i$ and $a_j$ can communicate if and only if:

\begin{equation}
d_{\infty}(p_i, p_j) = \max(|x_i - x_j|, |y_i - y_j|) \le r
\end{equation}

where $r \in \mathbb{Z}_{\ge 0}$ is the communication range parameter. This distance metric naturally models grid-based communication: an agent at position $(x, y)$ can communicate with all agents in a square region of size $(2r+1) \times (2r+1)$ centered at $(x, y)$.

The Chebyshev distance is chosen for three reasons:

\begin{enumerate}
    \item \textbf{Grid alignment:} It naturally corresponds to the maximum number of grid steps required to reach another agent, making it intuitive for grid-based environments.

    \item \textbf{Computational efficiency:} Computing Chebyshev distance requires only two subtractions, one absolute value operation, and one maximum operation, making neighbor queries very efficient.

    \item \textbf{Symmetric neighborhoods:} The resulting communication neighborhoods are square and symmetric, simplifying analysis and visualization.
\end{enumerate}

\subsection{Environmental Constraints}

The environment is \emph{static}: once a fruit item is collected, it does not regenerate. This constraint isolates the effects of communication range on exploration and coordination without the additional complexity of resource dynamics. The total available fruit is fixed at initialization, making the problem a finite-horizon resource collection task.

The grid is \emph{non-toroidal}: agents cannot wrap around edges. This creates boundary effects where agents near edges have fewer potential neighbors and less explorable space, modeling realistic spatial constraints.

\section{Simulation Implementation}

\subsection{Framework Selection}

The simulations are implemented using Mesa 3.0, a Python agent-based modeling framework specifically designed for social science and complex systems research. Mesa provides:

\begin{itemize}
    \item \textbf{Spatial structures:} Built-in support for grid-based environments with efficient neighbor queries using Chebyshev distance.
    \item \textbf{Agent scheduling:} Flexible activation regimes including random shuffling to avoid ordering artifacts.
    \item \textbf{Data collection:} Integrated tools for collecting agent-level and model-level metrics across simulation runs.
    \item \textbf{Batch execution:} Support for parameter sweeps with multiple replications and parallel execution.
    \item \textbf{Reproducibility:} Explicit random seed management ensuring deterministic results.
\end{itemize}

Mesa's modular architecture separates model components (agents, environment, scheduler) from analysis tools (data collection, visualization), enabling systematic experimentation while maintaining code clarity and interpretability.

\subsection{Environment Configuration}

\textbf{Grid dimensions.} The environment is a $30 \times 30$ non-toroidal grid, providing 900 cells. This size is chosen to balance:
\begin{itemize}
    \item Sufficient spatial extent for meaningful exploration and communication range effects
    \item Computational efficiency for running hundreds of replications
\end{itemize}

\textbf{Resource distribution.} Fruit is placed randomly at initialization with density $\rho \in \{0.15, 0.25\}$, representing the fraction of grid cells containing fruit. For a $30 \times 30$ grid:
\begin{itemize}
    \item $\rho = 0.15$: approximately 135 fruit items (sparse environment)
    \item $\rho = 0.25$: approximately 225 fruit items (dense environment)
\end{itemize}

Each cell contains at most one fruit item. Fruit is removed immediately upon harvesting and does not regenerate, creating a finite resource pool that depletes over time.

\textbf{Time horizon.} Each simulation run executes for $T = 500$ discrete time steps. This duration is sufficient for agents to explore a significant portion of the environment and harvest most available resources, while remaining computationally tractable for extensive parameter sweeps.

\subsection{Agent Architecture: BDI Framework}

Each agent employs a Belief-Desire-Intention (BDI) architecture, a well-established model for autonomous agent decision-making. The BDI framework provides a structured approach to modeling rational agents that:

\begin{itemize}
    \item Maintain \textbf{beliefs} about the world state
    \item Form \textbf{desires} representing goals to achieve
    \item Commit to \textbf{intentions} as concrete plans of action
\end{itemize}

In the context of fruit harvesting, the BDI components are instantiated as follows:

\textbf{Beliefs:} Each agent maintains a belief set $B_i \subseteq \mathcal{G}$ representing known fruit locations. Beliefs are updated through:
\begin{itemize}
    \item \textbf{Local sensing:} Detecting fruit in the Moore neighborhood (8 adjacent cells)
    \item \textbf{Communication:} Receiving fruit location messages from nearby agents
    \item \textbf{Belief revision:} Removing locations when fruit is harvested or found to be empty
\end{itemize}

\textbf{Desires:} The agent's primary desire is to maximize personal harvest yield, which aligns with the collective objective when combined with information sharing.

\textbf{Intentions:} At each time step, the agent selects a target location $\tau_i \in B_i \cup \{\text{null}\}$ representing its current intention:
\begin{itemize}
    \item If $B_i \neq \emptyset$: select the nearest known fruit location as target
    \item If $B_i = \emptyset$: set $\tau_i = \text{null}$ and enter exploration mode
\end{itemize}

\subsection{Behavioral Cycle}

Each agent executes a three-phase behavioral cycle at every time step:

\begin{enumerate}
    \item \textbf{Move:}
    \begin{itemize}
        \item If $\tau_i \neq \text{null}$: move one cell toward target using greedy path selection (minimize Chebyshev distance)
        \item If $\tau_i = \text{null}$: move randomly to an adjacent cell (exploration)
    \end{itemize}

    \item \textbf{Harvest:}
    \begin{itemize}
        \item If current cell contains fruit: harvest it (increment personal yield, remove from environment)
        \item Update beliefs to remove harvested location
        \item Sense Moore neighborhood and add any discovered fruit to beliefs
    \end{itemize}

    \item \textbf{Communicate:}
    \begin{itemize}
        \item If $B_i \neq \emptyset$ and $r > 0$: broadcast belief set to all agents within range $r$
        \item Receive messages from nearby agents and merge new locations into $B_i$
        \item Increment message counter for efficiency analysis
    \end{itemize}
\end{enumerate}

This cycle implements a simple but effective coordination strategy: agents exploit known resources when available (guided by beliefs) and explore randomly when no information is available. Communication enables agents to share discoveries, reducing redundant exploration.

\subsection{Communication Protocol: Selective Broadcasting}

Communication is implemented as \emph{selective broadcasting} within a Chebyshev radius $r$. This protocol balances information sharing with communication efficiency:

\textbf{Range constraint:} An agent $a_i$ at position $p_i$ can send messages to all agents $a_j$ satisfying:
\begin{equation}
d_{\infty}(p_i, p_j) = \max(|x_i - x_j|, |y_i - y_j|) \le r
\end{equation}

\textbf{Selective transmission:} Agents only broadcast when they have information to share ($B_i \neq \emptyset$). This prevents unnecessary message overhead when agents have no knowledge to contribute.

\textbf{Message content:} Each message contains the sender's complete belief set—the set of fruit locations the sender currently believes are available. This simple protocol ensures that all discovered information propagates through the network.

\textbf{Message handling:} Upon receiving a message, an agent merges the received locations into its own belief set using set union: $B_i \leftarrow B_i \cup B_{\text{received}}$. Duplicate locations are automatically eliminated through set semantics.

\textbf{Belief validation:} When an agent reaches a target location and finds no fruit (because another agent harvested it first), the location is removed from beliefs. This implements a simple form of belief revision that prevents agents from pursuing stale targets indefinitely.

\textbf{Cost measurement:} Communication cost is measured as the total number of messages sent during a simulation run. Each broadcast to $k$ neighbors counts as $k$ messages, reflecting the bandwidth and processing overhead of information transmission. This metric serves as a proxy for:
\begin{itemize}
    \item Bandwidth consumption in wireless communication
    \item Computational overhead for message processing
    \item Energy expenditure in battery-powered robots
\end{itemize}

\subsection{Communication Range Configurations}

The study evaluates five communication range values:

\begin{itemize}
    \item $r = 0$ (no communication): Agents operate independently with no information sharing. This baseline isolates the contribution of communication to collective performance.

    \item $r = 2$ (local communication): Agents communicate within a $5 \times 5$ neighborhood. This represents short-range communication typical of Bluetooth or local radio.

    \item $r = 4$ (medium communication): Agents communicate within a $9 \times 9$ neighborhood, covering a moderate spatial extent.

    \item $r = 6$ (long-range communication): Agents communicate within a $13 \times 13$ neighborhood, approaching grid-wide connectivity in a $30 \times 30$ environment.

    \item $r = 8$ (very long-range communication): Agents communicate within a $17 \times 17$ neighborhood, providing near-global connectivity for most agent positions.
\end{itemize}

These values are chosen to span a range from isolated operation to near-complete connectivity, enabling identification of optimal intermediate ranges.

\section{Experimental Design}

\subsection{Factorial Design}

The experiment employs a full factorial design with three independent variables:

\begin{enumerate}
    \item \textbf{Communication range:} $r \in \{0, 2, 4, 6, 8\}$ (5 levels)
    \item \textbf{Team size:} $N \in \{10, 20\}$ (2 levels)
    \item \textbf{Resource density:} $\rho \in \{0.15, 0.25\}$ (2 levels)
\end{enumerate}

This yields $5 \times 2 \times 2 = 20$ unique parameter configurations. Each configuration is replicated 20 times with different random seeds, producing $20 \times 20 = 400$ total simulation runs.

\textbf{Rationale for factor selection:}

\begin{itemize}
    \item \textbf{Communication range} is the primary independent variable of interest, varied systematically to identify optimal values.

    \item \textbf{Team size} affects agent density and potential for coordination. Larger teams may benefit more from communication but also face greater coordination overhead.

    \item \textbf{Resource density} influences the exploration-exploitation trade-off. Sparse environments require more exploration, while dense environments may benefit more from coordination to avoid redundant harvesting.
\end{itemize}

\subsection{Dependent Variables and Metrics}

The study collects multiple metrics to comprehensively evaluate communication range effects:

\textbf{Primary metric:}
\begin{itemize}
    \item \textbf{Total yield} ($Y$): The total number of fruit items harvested by all agents over the 500-step episode. This directly measures collective task performance.
\end{itemize}

\textbf{Communication metrics:}
\begin{itemize}
    \item \textbf{Total messages sent} ($M$): The cumulative number of messages transmitted during the episode, measuring communication overhead.

    \item \textbf{Average messages per step}: $M / T$, normalizing communication cost by episode length.
\end{itemize}

\textbf{Efficiency metrics:}
\begin{itemize}
    \item \textbf{Communication efficiency}: $E = Y / M$ for configurations with $M > 0$, measuring yield per message exchanged. This captures the cost-effectiveness of communication.

    \item \textbf{Normalized efficiency}: Efficiency relative to baseline yield, enabling comparison across different environmental conditions.
\end{itemize}

\textbf{Environmental metrics:}
\begin{itemize}
    \item \textbf{Remaining fruit}: Number of unharvested fruit items at episode end, indicating exploration completeness.

    \item \textbf{Harvest rate}: Fraction of available fruit harvested, measuring task completion.
\end{itemize}

\subsection{Replication and Randomization}

\textbf{Replication strategy:} Each of the 20 parameter configurations is replicated 20 times using a fixed set of random seeds (0-19). This provides:
\begin{itemize}
    \item Sufficient statistical power to detect meaningful differences
    \item Reproducibility through deterministic seed sequences
    \item Quantification of variability through standard deviation estimates
\end{itemize}

\textbf{Randomization controls:}
\begin{itemize}
    \item \textbf{Fruit placement:} Random seed controls initial fruit distribution, ensuring different spatial patterns across replications while maintaining fixed density.

    \item \textbf{Agent initialization:} Agents start at random positions, preventing artifacts from fixed starting configurations.

    \item \textbf{Agent activation:} Mesa's RandomActivation scheduler shuffles agent execution order each step, eliminating ordering biases.

    \item \textbf{Movement ties:} When multiple moves yield equal distance to target, selection is randomized to prevent systematic biases.
\end{itemize}

\section{Data Analysis}

\subsection{Descriptive Statistics}

For each parameter configuration, summary statistics are computed across replications: mean yield, standard deviation, mean messages, and communication efficiency ($E = Y / M$).

\subsection{Comparative Analysis}

Communication-enabled configurations ($r > 0$) are compared against the baseline ($r = 0$) to quantify information sharing benefits. Performance improvements are reported as percentage change:

\begin{equation}
\Delta Y_r = \frac{\bar{Y}_r - \bar{Y}_0}{\bar{Y}_0} \times 100\%
\end{equation}

The analysis emphasizes \emph{practical significance} through efficiency metrics, identifying ranges that maximize yield-to-cost ratio rather than raw yield alone.

\section{Validation}

Model verification includes unit testing of agent behaviors, boundary testing at grid edges, and conservation law verification (fruit count decreases monotonically). Model validation is established through behavioral plausibility (agents move toward known resources, explore when uninformed) and emergent patterns matching theoretical expectations (clustering around resources, diminishing returns from excessive communication).

\section{Reproducibility}

The experimental protocol ensures reproducibility through fixed parameter grids, deterministic seeding (seeds 0-19), version control, and open access. All code, data, and analysis scripts are publicly available at \href{https://github.com/marufdevops/multiagent-cooperation-research}{GitHub}.. This study uses computational simulation with no human or animal subjects. Ethical considerations include transparent reporting of assumptions, appropriate generalization within modeled scope, and honest uncertainty quantification.

\section{Summary}

This chapter presented a comprehensive methodology for investigating communication range effects in multi-agent harvesting systems. The approach combines:

\begin{itemize}
    \item A formal problem formulation with explicit objective functions and constraints
    \item A BDI agent architecture providing interpretable autonomous behavior
    \item A selective broadcasting protocol with range-limited communication
    \item A full factorial experimental design with systematic parameter variation
    \item Statistical analysis and efficiency metrics
    \item Rigorous reproducibility and validation procedures
\end{itemize}

The methodology enables systematic investigation of the research question: \emph{What is the optimal communication range for maximizing collective yield in multi-agent fruit harvesting?} The following chapters present the implementation details and experimental results obtained through this methodology.
